OkHub 디자인 시스템

개발자가 문서, 코드, Issue와 리뷰를 한 화면에서 오래 읽을 수 있도록 정보 밀도와 편안함을 함께 다루는 초기 제품의 시각·상호작용 기준입니다.

01

원칙

화면별 HTML 시안보다 우선하며 shadcn primitive와 OkHub pattern에 동일하게 적용합니다.

읽기 편안한 밀도

탐색·Board·Settings는 compact하게, 문서·편집기·리뷰는 넉넉하게 표시합니다.

의미를 전달하는 색

행동과 상태를 표현하되 색상만으로 상태를 구분하지 않습니다.

Border-first

일반 콘텐츠는 얇은 테두리, 화면 위에 뜨는 요소에만 그림자를 사용합니다.

초기 범위: Light 테마를 우선 지원하고 토큰은 역할 중심으로 이름을 붙여 이후 Dark 테마로 확장할 수 있게 합니다.
02

브랜드 표기

제품 안에서는 짧고 일관된 이름을 사용합니다.

OK
OkHub앱 화면의 짧은 표기
정식 프로젝트명

Git 저장소와 프로젝트에서는 okf-knowledge-hub를 유지합니다.

  • Aqua Mint 배경에 흰색 OK를 넣은 현재 로고 마크는 임시 형태입니다.
  • 흰색은 로고의 OK와 충분히 어두운 Primary action 배경의 버튼 label에만 사용합니다. Aqua Mint 위 일반 텍스트에는 사용하지 않습니다.

08

컴포넌트 구조

shadcn은 완성품이 아니라 접근 가능한 primitive 기반으로 사용합니다.

components/ui
├─ Button
├─ Input
├─ Dialog
├─ Popover
├─ DropdownMenu
└─ Tooltip
components/patterns
├─ StatusBadge
├─ SettingsRow
├─ DocumentTreeItem
├─ ReviewComment
├─ DecisionRequest
└─ RepositoryConnection
  • components/ui는 색상, 밀도, focus, radius와 상태 variant를 소유합니다.
  • components/patterns는 OkHub에서 반복되는 제품 의미와 조합을 소유합니다.
  • 화면에서 임의 Tailwind class로 동일 패턴을 다시 만들지 않습니다.
  • pattern은 데이터 fetching이나 Git/GitHub mutation을 직접 수행하지 않습니다.

09

상태와 피드백

작업 규모와 사용자의 판단 필요 여부에 맞는 피드백을 사용합니다.

  • Hover는 배경과 색상만 120–160ms로 변경합니다.
  • Pressed는 Hover보다 한 단계 진한 배경을 사용합니다.
  • Selected는 Primary soft 배경, 활성 텍스트와 필요한 경우 왼쪽 표시선을 사용합니다.
  • Focus는 2px Aqua Mint ring과 바깥 offset을 사용합니다.
  • Disabled는 명도와 대비를 낮추되 설명은 읽을 수 있어야 합니다.
  • 버튼 작업은 LoaderCircle, 화면 최초 로딩은 skeleton을 사용합니다.
  • Form 오류는 field 아래에 원인과 해결 방법을 표시합니다.
  • 짧은 Git·동기화 성공 결과는 toast로 표시합니다.
  • 충돌, 인증, push 실패는 본문 또는 Dialog에서 판단할 수 있게 합니다.
  • 삭제·연결 교체·변경 폐기는 대상 이름이 포함된 확인 Dialog를 사용합니다.

Dialog와 panel 전환은 160–200ms로 제한하고 prefers-reduced-motion에서는 기능에 필요하지 않은 애니메이션을 제거합니다. 전체 화면 spinner는 사용하지 않습니다.

13

접근성

색, 키보드, focus와 확대 환경을 함께 검증합니다.

  • 일반 텍스트와 control label은 WCAG AA 대비를 목표로 합니다.
  • 색상만으로 상태, 선택과 오류를 전달하지 않습니다.
  • 키보드로 모든 action과 overlay에 접근할 수 있어야 합니다.
  • Dialog는 focus trap을 사용하고 닫힌 뒤 trigger로 focus를 돌려줍니다.
  • Tooltip은 hover뿐 아니라 keyboard focus에서도 노출합니다.
  • icon-only button은 접근 가능한 이름을 갖습니다.
  • OS 확대와 앱 zoom에서 중요한 content와 action이 잘리지 않아야 합니다.
14

초기 범위와 검증

지금 지원할 것과 의도적으로 제외한 것을 분리합니다.

초기 범위
  • Light 테마
  • Default / Compact 표시 밀도
  • macOS / Windows 데스크톱
  • shadcn primitive와 OkHub pattern
제외
  • Dark 테마
  • 사용자 정의 Primary 색상
  • 워크스페이스가 강제하는 팀 공용 표시 밀도
  • 문서 타입·담당 영역별 장식 색상

구현 검증 체크리스트

  • primitive의 모든 variant와 상태를 Storybook 또는 동등한 component preview에서 확인합니다.
  • Default와 Compact로 Home, Documents, Project, 문서 상세와 Settings를 확인합니다.
  • keyboard navigation, focus 복귀, tooltip과 Dialog를 검사합니다.
  • Primary와 Semantic foreground/background 대비를 자동 검사합니다.
  • macOS와 Windows에서 Pretendard fallback, control 높이와 scroll 영역을 확인합니다.
