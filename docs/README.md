## 문서 상태 표기

- **합의**: 현재 대화에서 방향이 확인된 내용
- **후보**: 추천 방향이 있으나 추가 확인이 필요한 내용
- **미결정**: 선택지 조사와 팀 합의가 필요한 내용

제품 문서는 합의한 요구와 제약의 원본이고, 구현 순서·파일·테스트는 별도의 구현 계획에서 관리합니다. 미결정으로 표시한 항목은 해당 구현 단계에 들어가기 전에 확정합니다.
