# OkHub 시작하기

OkHub는 내 기기에서 문서를 작성하고, GitHub의 작업 이슈·PR·검토를 연결해 사용하는 로컬 협업 앱입니다. 별도 웹서버를 실행하거나 서비스를 배포할 필요 없이 앱을 열어 사용합니다. 왼쪽 메뉴에서 필요한 기능의 사용 방법을 확인하세요.

## 가이드 구성

| 분류 | 안내 내용 | 현재 범위 |
| --- | --- | --- |
| 문서 | 작성·편집, 자동 저장, 발행, 검토 요청과 리뷰, 초안 복구 | 문서 작업의 진행 방법과 상태 안내 |
| 프로젝트 | 보드·목록, Iteration, Issue와 관련 문서·PR | 사용법 준비 중. 화면 연결 후 상세 안내 추가 |

기능을 선택하면 왼쪽에는 세부 목차가, 오른쪽에는 해당 기능의 설명이 표시됩니다. 모바일에서는 상단의 `가이드 메뉴`를 펼쳐 이동할 수 있습니다.

## 문서 작업 시작하기

1. **Documents**에서 문서를 찾거나 `새 문서`를 선택합니다.
2. 내용을 작성하고 자동 저장 상태를 확인합니다.
3. 준비가 되면 `발행`에서 변경 내용을 비교합니다.
4. 바로 발행하거나, 검토가 필요하면 PR로 검토를 요청합니다.

세부 버튼과 상태의 의미는 **문서** 메뉴에서 확인하세요. 자동 저장, 검토 요청과 발행은 서로 다른 동작입니다.

## 로컬 작업과 GitHub 공유

작성 중인 초안은 내 기기에 저장합니다. 자동 저장만으로 GitHub에 전송하거나 다른 사람에게 공유하지 않습니다.

PR 공유, 원격 변경 확인과 발행 등 GitHub를 사용하는 작업에는 네트워크 연결과 해당 저장소의 권한이 필요합니다. 로컬 앱이라는 것은 별도 서버를 운영하지 않는다는 뜻이며, GitHub와의 동기화까지 모두 오프라인으로 처리한다는 뜻은 아닙니다.

## 가이드 읽기

이 사용 가이드는 로컬 HTML 파일로도 읽을 수 있습니다. 가이드 열람을 위해 서버를 실행하거나 네트워크에 연결할 필요는 없습니다. HTML을 다른 위치로 옮길 때는 연결된 스타일·동작 파일도 함께 옮겨주세요.
